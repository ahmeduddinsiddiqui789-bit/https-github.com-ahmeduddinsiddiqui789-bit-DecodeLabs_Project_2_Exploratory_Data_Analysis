DecodeLabs Project 2: Exploratory Data Analysis

Project Overview

This project performs Exploratory Data Analysis (EDA) on an e-commerce orders dataset as part of the DecodeLabs Data Analytics Industrial Training Kit.

The objective is to understand the dataset, calculate descriptive statistics, identify patterns and trends, investigate outliers, and summarize key observations.

Dataset

- File: Dataset for Data Analytics.xlsx
- Records: 1,200
- Columns: 14
- Date range: January 2023 to June 2025

The dataset contains information about orders, customers, products, quantities, prices, payment methods, order statuses, coupon codes, and referral sources.

Tools and Libraries

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

Analysis Performed

1. Loaded and inspected the dataset.
2. Checked missing values and duplicate records.
3. Prepared date columns for time-based analysis.
4. Calculated mean, median, count, and descriptive statistics.
5. Analyzed products, order statuses, payment methods, and referral sources.
6. Visualized product distribution and order value.
7. Analyzed monthly order-value trends.
8. Identified potential outliers using the IQR method.
9. Examined correlations between numerical variables.

Key Observations

- The dataset contains 1,200 records and 14 columns.
- The CouponCode column contains missing values that were handled during preparation.
- Printer has the highest number of order records in the dataset.
- Chair has the highest combined TotalPrice among the products.
- Cancelled is the most frequent order status.
- The notebook investigates order-value distributions, monthly trends, potential outliers, and correlations.

Conclusion

This project demonstrates the use of Python for data cleaning, descriptive statistics, data visualization, and exploratory analysis. The findings help identify patterns in order data and support further investigation.
